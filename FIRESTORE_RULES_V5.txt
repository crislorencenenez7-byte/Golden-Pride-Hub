Golden Pride Hub v5 — Firestore rule addition

The new Live Broadcast feature uses a collection named: broadcasts

Add an admin-only rule for broadcasts. Example (merge into your existing rules):

match /broadcasts/{broadcastId} {
  allow read: if request.auth != null;
  allow create, update, delete: if request.auth != null
    && get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
}

Keep your existing users/announcements/events/gallery/achievements rules.
Do not replace your complete rules file blindly; merge this match block into it.
