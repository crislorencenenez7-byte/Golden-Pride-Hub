Golden Pride Hub 4.3 — Broadcast note

The public Home page (index.html) must be able to read broadcasts.
The complete rules are in FIRESTORE_RULES_V4.3_FINAL.txt.

Required block:

match /broadcasts/{broadcastId} {
  allow read: if true;
  allow create, update, delete: if isAdmin();
}

Only authenticated admins whose users/{uid}.role is exactly "admin"
can create, update, or delete broadcasts.
